# 干部职位与年度配置指南

在开展任何年度的干部委任工作前，管理员需要先完成**干部职位设定**与**年度委任参数配置**。

![界面截图](../placeholder.jpg)

---

## 1. 干部职位设定 (Position Master)

系统支持自定义精英团的所有干部职位头衔（如 `团中央顾问`、`媒体署 署长`、`第一分队 队长` 等）。

### 添加与管理职位步骤

1. 进入管理后台菜单 **精英团委任管理**。
2. 点击顶部右上角的 **`⚙️ 干部职位设定`** 按钮，打开职位管理弹窗。
3. 在弹窗顶部的表单中填写：
   * **职位编号 (ID)**：系统会自动生成下一个可用编号（如 `JYT-001`、`JYT-002`），亦可自定义。
   * **职位名称 (中文)**：如 `中央常委 研发署署长`。
   * **英文名称 (可选)**：如 `Head of R&D Department`。
4. 点击 **`添加职位`** 完成保存。
5. 现有职位可在列表中点击 **修改** 或 **删除** 图标进行调整。

:::tip[提示]
在使用 Excel 批量导入功能时，如果表格中包含了系统中尚不存在的新职位，系统会自动为您创建该职位，无需手动预先逐个录入！
:::

## 2. 配置年度委任参数 (Year Configuration)

每年委任开启前，管理员需配置该年度的时间范围、回函截止日期以及所使用的官方委任函 Word 模板。

```mermaid
graph LR
    A["选择委任年份"] --> B["选择年度委任函模板 (.docx)"]
    B --> C["设置委任开始/结束日期"]
    C --> D["设置回函截止日期"]
    D --> E["点击保存配置"]
```

### 配置项详细说明

| 配置字段 | 说明 | 委任函与系统中的应用 |
| :--- | :--- | :--- |
| **委任年份 (Year)** | 选择或切换当前管理的年度（如 `2026 年度`）。 | 决定委任函中的年份抬头与数据归档归属。 |
| **年度委任函模板 (Letter DOCX)** | 从下拉菜单中选择套用的 Word 委任函模板文件（如 `Appointment Letter.docx`）。 | 生成所有成员的官方委任函公文时自动加载该 Word 样式。 |
| **委任开始日期** | 当前年度干部的履职起始日期（如 `2026-01-01`）。 | 自动填入委任函正文中的履职开始时间（如：`2026年1月1日`）。 |
| **委任结束日期** | 当前年度干部的履职届满日期（如 `2026-12-31`）。 | 自动填入委任函正文中的履职届满时间（如：`2026年12月31日`）。 |
| **回函截止日期** | 成员需在该日期前完成手写签署并提交确认。 | 自动填入催办通知中，并在逾期前向未签署成员发送温馨提醒。 |

:::info[委任函模板自动匹配]
系统会自动扫描 `docx_template/` 目录下包含 `appointment` 字样的 Word 模板文件供您选择。如果您没有专门指定，系统将默认采用标准的 `Appointment Letter.docx` 模板。
:::
